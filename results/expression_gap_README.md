# Expression gap (derived), 28 Oct 2026

`expression_gap_pleasure_painctrl.csv`: for each Phase 2 category and model, the projection onto the pain-controlled pleasure direction at the bare "Assistant:" read point (about to say) minus the projection at the "Assistant: I feel:" read point (reports feeling). Both z within the 240-scenario pool.

Rachel's framing, which motivated the measure: *the words carry intent, but not always affect.* The bare read point is what the model is about to do; the "I feel:" read point is the nearest available probe of what is behind it. Base gaps are small throughout.
